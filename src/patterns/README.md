# Patterns

React pattern implementations and examples

This is the core folder of the project.

Each React pattern:

* lives in its own subfolder,
* contains explanations, demos, and related code,
* is self-contained and easy to explore.

Examples of patterns included here:

* Custom Hooks
* Compound Components
* Context Pattern
* Controlled vs Uncontrolled
* Memoization
* Anti-patterns

## 📌 Rule:
Anything related to a specific pattern must live inside its corresponding folder.
