# Components

Reusable, presentational components

This folder contains generic UI components that:

* are not tied to a specific React pattern,
* do not contain complex business logic,
* can be reused across multiple parts of the application.

 Typical examples:

* Buttons
* Cards
* Badges
* Simple UI elements
* Visual wrappers

## 📌 Rule:
Components in this folder should focus on rendering UI only and receive all data through props.
